# Futuristic Eye

A mesmerizing WebGL-based animation of a futuristic eye, created using HTML, CSS, and JavaScript. This project features a 3D rendered eye with dynamic lighting, tunnels, and interactive controls.

## Demo

Check out the live demo: [Futuristic Eye](https://binaryvortex.github.io/Futuristic-Eye/)

![Screenshot](Screenshot%202024-08-22%20191122.png)

## Features

- **WebGL Rendering**: Utilizes WebGL2 for high-performance 3D graphics.
- **Interactive Controls**: Mouse interaction for camera rotation.
- **Responsive Design**: Adapts to different screen sizes.
- **Shader Effects**: Custom fragment shaders for realistic lighting and effects.

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/BinaryVortex/Futuristic-Eye.git
   ```
2. Open `index.html` in your web browser.

Alternatively, view the live version on GitHub Pages.

## Technologies Used

- HTML5
- WebGL2
- JavaScript (ES6+)
